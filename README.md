# We Don't Use AI

A simple, responsive one-page website for a human-powered task service. The site is a single static `index.html` file with no build tools, dependencies, trackers, or externally hosted fonts.

## Before publishing

Review the contact section in `index.html` and set your real phone number if needed. The site is intentionally simple and designed to work without email.

## Publish for free with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)`, then save.
4. GitHub will show the published URL in the Pages settings once deployment finishes.

No build step is needed.
